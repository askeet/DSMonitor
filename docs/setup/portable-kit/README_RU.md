# Codex + DeepSeek + Forge Delegate — Первая установка на Windows

Для чистой Windows, без существующей резервной копии.

## 1. Установить основные программы

Установить вручную:

- Codex Desktop и войти в аккаунт.
- Node.js LTS, включая npm.
- Git, если необходим для проектов.

## 2. Установить зависимости

Запустить `Install-Dependencies.bat`, проверить версии пакетов и подтвердить установку словом `INSTALL`.

Версии по умолчанию:

- OpenCode `2.2.6`
- Forge Delegate `1.2.4`

Это версии, закреплённые в portable-kit, не обязательно последние доступные релизы.

## 3. Подключить DeepSeek

Выполнить в PowerShell:

```powershell
opencode auth login deepseek
```

Ввести API-ключ DeepSeek через процедуру авторизации OpenCode.

## 4. Подключить Forge Delegate к Codex

После согласия на изменение MCP-конфигурации выполнить:

```powershell
forge-delegate setup --targets codex --scope user --model "deepseek/deepseek-flash" --no-skill
```

Параметр `--no-skill` предотвращает установку стандартного `delegate-work` вместо нашей настроенной версии.

Команда регистрирует MCP-сервер в пользовательской конфигурации Codex. Она также может установить launcher с автоматическим обновлением, который необходимо проверить в шаге 6.

## 5. Настроить внешнего исполнителя

Скопировать полный проверенный `deepseek-bounded.md` из portable-kit в:

`%USERPROFILE%\.config\opencode\agents\deepseek-bounded.md`

Сохранить оригинальные инструкции и параметры:

- `mode: primary`
- `model: deepseek/deepseek-flash`
- `steps: 120`

Не заменять полные инструкции агента сокращённым примером. Если portable-kit не содержит полного файла, получить проверенную конфигурацию перед продолжением установки.

Открыть:

`%USERPROFILE%\.forge-delegate\config.json`

Проверить следующие поля:

```json
{
  "defaultModel": "deepseek/deepseek-flash",
  "defaultAgent": "deepseek-bounded",
  "autoApprove": false
}
```

Это пример требуемых полей, а не полный конфигурационный файл. Сохранить все остальные существующие настройки.

## 6. Проверить безопасность Forge Delegate

### Подтверждение действий

- Убедиться, что `autoApprove` явно установлен в `false`.
- Проверить, что профили и отдельные вызовы `delegate` не переопределяют его на `true`.
- Проверить соответствие модели, исполнителя и директории проекта настройкам и разрешениям.

**Важно:** при `autoApprove: false` действия фонового исполнителя, требующие подтверждения, могут быть отклонены или заблокированы, если интерактивное подтверждение недоступно. Не обходить это ограничение включением автоматического одобрения без явного разрешения.

### Автоматические обновления

Открыть:

`%USERPROFILE%\.codex\config.toml`

Найти MCP-сервер Forge Delegate и проверить команду запуска.

- Если непосредственно запускается `forge-delegate.cmd`, механизм автообновления `launcher.mjs` не используется.
- Если используется `start-mcp.cmd`, проверить, что именно запускает этот wrapper.
- Если используется автообновляемый `launcher.mjs`, отключить автоматическое обновление:

```bat
set "FORGE_AUTO_UPDATE=0"
```

Для `.cmd`/`.bat` добавить строку перед запуском launcher.

Если Codex запускает `launcher.mjs` напрямую, передать `FORGE_AUTO_UPDATE=0` через настройки окружения MCP-сервера.

Не изменять системные переменные Windows.

После изменения MCP-конфигурации перезапустить Codex Desktop.

**Перед первым делегированием проверить:**

- `autoApprove: false`.
- Автообновления отключены, если используется соответствующий launcher.
- Правильно указаны провайдер и модель.
- Выбран нужный bounded-agent.
- Разрешены директория проекта и необходимый доступ к исходникам.

## 7. Установить глобальные skills

Скопировать обе папки целиком из:

`docs/setup/.agents/skills/`

в:

`%USERPROFILE%\.agents\skills\`

Необходимые skills:

- `cost-efficient-coding`
- `delegate-work`

Сохранить вложенные файлы, включая:

`cost-efficient-coding/references/`

Основной skill `cost-efficient-coding` управляет процессом разработки, разрешениями, архитектурными решениями, бюджетами исправлений и независимым QA.

Вспомогательный `delegate-work` содержит технические инструкции для Forge Delegate.

## 8. Включить глобальные инструкции Codex

Создать или дополнить:

`%USERPROFILE%\.codex\AGENTS.md`

Добавить:

```markdown
For coding tasks, consider cost-efficient-coding.
Apply its workflow when relevant, including explicit
external delegation requests.
```

Сохранить все существующие глобальные инструкции.

## 9. Проверить установку

1. Запустить `Verify-Delegate.bat`.
2. Перезапустить Codex Desktop.
3. Проверить доступность Forge Delegate MCP и обоих skills.
4. Убедиться, что выбранный исполнитель соответствует конфигурации OpenCode и Forge Delegate.
5. При желании выполнить одну явно разрешённую низкорисковую тестовую делегацию. Она расходует DeepSeek API-кредиты.

Офлайн-проверка не подтверждает фактическую авторизацию провайдера, доступность модели, успешность делегирования или соблюдение лимита шагов во время выполнения.

При первом внешнем делегировании в новом проекте `cost-efficient-coding` должен предложить короткий выбор разрешений. После явного согласия пользователя они записываются в корневой `AGENTS.md` проекта и используются повторно в пределах согласованного доступа.

## После установки

- Запустить `Backup-Delegate.bat` для создания резервной копии настроенного окружения.
- Использовать `Restore-Delegate.bat` только для восстановления из ZIP.
- Шифровать ZIP-файлы и хранить их вне Git-репозиториев.
- Не разрешать AI-агентам запускать установочные скрипты или восстановление без отдельного явного согласия.
